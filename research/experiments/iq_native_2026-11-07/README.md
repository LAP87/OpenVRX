# Saved-code native fidelity experiment

Exact private task84 helpers and unchanged time-logging bench, Core031bba0. These are provenance copies; the original manifests refer to private saved IQ-demodulated code bytes and model outputs. They are not a standalone simulator launcher for a new machine. No source/model/native retry is required to read the published results.

The native coordinator runs one declared case. review.py independently parses all emitted words and timestamps, checks actual compiled parameters, reuses model pixel metrics only after byte identity, and checks six owned integrity damages. A successful coordinator or review does not accept image quality, the complete receiver or hardware.
